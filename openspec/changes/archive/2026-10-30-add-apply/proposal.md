# Change: plan и apply по SSH

## Why
Состояние в git должно приводить хосты к себе безопасно: с дифом перед применением, валидацией конфигов, пробой цепочки и откатом, с учётом джамп-хостов и порядка применения.

## What Changes
- `plan`: рендер, сверка хэшей файлов на хостах по SSH, диф, обнаружение дрейфа, недоступные хосты
- `apply [--host] [--branch] [--force]`: guard'ы, порядок от листьев к джампу, копирование через stdin, `-test`, атомарная подмена, reload, проба, маркер коммита, откат при неудаче, тег
- SSH-слой: спавн системного `ssh` с `-J` по полю `via`, ControlMaster, запись host key в состояние при bootstrap
- Проба цепочки через probe-socks на входе

## Impact
- Модули `ssh`, `plan`, `apply` в `vpnctl-core`
- Зависит от `add-state-model`, `add-render`
